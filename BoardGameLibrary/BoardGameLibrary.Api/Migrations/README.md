# EF Core migrations

These files are generated by EF Core and define the database schema history for the local SQLite database.

Create a new migration only when the domain model changes:

    dotnet ef migrations add <MigrationName> --project BoardGameLibrary.Api --startup-project BoardGameLibrary.Api

Apply existing migrations to a local database with:

    dotnet ef database update --project BoardGameLibrary.Api --startup-project BoardGameLibrary.Api

The `DbContextModelSnapshot` tracks the model state used when generating future migrations. Migration files should be reviewed after generation but not manually rewritten for convenience.
